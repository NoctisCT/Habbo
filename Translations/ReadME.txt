Just need to unpack the "Navicat Premium Portable", click on Connection > MySQL > Next > Ok (if you're using IIS or change the password for MySQL, just type your password. If you're using the Pack AIO - Arcturus Edition V4, don't worry, just click in OK)

Done? Double click on 'localhost_3306', and something called habbo will appear

Double click on Habbo, right click on habbo and click on Execute SQL File...

File: Select the catalog_pages you want

BR = Portuguese
EN = English (original)
ES = Spanish
FR = French
IT = Italian
NL = Dutch
TR = Turk

Disable the option 'Run multiple queries in each execution' and click on Start.
